# アプリ！りまいんど！

指定した時刻に通知や全画面アラームを鳴らすアプリです。

## 主な機能

- アラームの作成・編集・削除、繰り返し曜日、日付指定、除外日
- ホームから「1分後・5分後・10分後・30分後」にすぐ鳴らすクイックアラーム
- 通知、合成音声、全画面アラーム。音量・音・再通知回数はアラームごとに設定
- アプリ名検索・並べ替え、カレンダー予定の取り込み
- 計算／QR停止チャレンジ、段階的再通知、アラーム別音量
- 履歴・曜日／時間帯別統計、ホーム画面ウィジェット、クイック設定タイル
- JSONバックアップ／復元、スマートウォッチへの通知ミラーリング

## 最初に確認する設定

1. アプリの通知を許可します。
2. 設定の「権限と動作状況」から、Android 12以降は「正確なアラーム」、Android 14以降は「全画面通知」を許可します。
3. 通知が画面上部に出ない場合は、同じ画面の「通知バナー（画面上部）の設定」を開き、「ポップアップ表示」を有効にします。おやすみモードや端末メーカーの省電力設定でも表示・鳴動が抑制されることがあります。
4. 合成音声を使う場合は、端末に日本語の音声合成エンジン／音声データがあることを確認します。読み上げ音量はAndroidの通知音量が基準です。
5. カレンダー連携にはカレンダー権限、QRチャレンジには対応スキャナーアプリが必要です。バックアップはファイル選択画面でGoogle Drive等を保存先に選びます。自動同期ではありません。

## ビルド

GitHub Actionsで「Build Android APK」を実行すると、`./gradlew assembleDebug` でAPKを作成します。ローカルビルドにはJDK 17とAndroid SDK 34が必要です。Windowsではプロジェクトルートで `gradlew.bat assembleDebug` を実行してください。

既存の `appalarm_prefs` と `alarm_list_json` を維持し、追加設定は既定値で読み込むため、既存アラームとの互換性を保ちます。
