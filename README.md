# アプリ起動アラーム (AppAlarm) for Android

指定した時刻になると「このアプリを開きますか？」と確認通知または全画面アラームを出し、ワンタップで目的のアプリを開く Android アプリケーションです。

## 主な機能と改善点

1. **クイック設定タイル／ウィジェット拡張**
   - **クイック設定タイル (`AlarmTileService`)**: 通知パネルのタイルから次のアラームを確認し、1タップで即座にON/OFF切り替え。
   - **ホーム画面ウィジェット (`WidgetProvider`)**: ウィジェット上の「ON / OFF」ボタンでアプリを開かずに即座に有効/無効を切り替え。

2. **音量フェードイン (`WakeActivity` & 設定)**
   - アラーム鳴動時、小さい音量から徐々に大きく。設定でON/OFFおよび秒数（5秒 / 10秒 / 20秒 / 30秒）を変更可能。

3. **履歴・統計・二度寝分析 (`HistoryActivity` & 設定)**
   - 「停止」「スヌーズ」「自動起動」「通知」のアクション履歴を記録。
   - スヌーズ回数の多いアラーム（寝坊注意アラーム）を自動分析。
   - 「履歴を保存する」設定をOFFにして履歴を一切残さないプライバシー保護にも対応。

4. **グループ／タグ整理 (`MainActivity` & `EditActivity`)**
   - 「朝」「仕事」「夜」「休日」などのタグでアラームを整理。
   - メイン画面上部のチップバーでワンタップ絞り込み。

5. **Material 3 デザイン / ダークモード / システムカラー連携**
   - 全画面を Material 3 のテーマ配色で構成。ライト・ダークどちらでも文字が読めます。
   - 設定画面の「画面のテーマ」でシステム連動 / ライト / ダークを選択可能。
   - Android 12 以降は「システムの色を使う (Material You)」で壁紙の色をアプリ全体に適用（ON/OFF切り替え可）。

6. **継続的なアップデート（上書き更新インストール保証）**
   - リポジトリに固定のデバッグキーストア (`app/debug.keystore`) を同梱し、署名設定を一元化。
   - GitHub Actions のビルド番号（`GITHUB_RUN_NUMBER`）と連動して `versionCode` が自動インクリメントされるため、**毎回アプリをアンインストールすることなく、ダウンロードした最新APKをそのまま上書き更新インストール可能**です。

---

## GitHubでのビルドとインストール手順

1. 本リポジトリの変更を GitHub にプッシュします。
   ```bash
   git add .
   git commit -m "Fix gradle wrapper and add dynamic colors"
   git push origin main
   ```
2. GitHub リポジトリの **Actions** タブを開きます。
3. **Build Android APK** ワークフローの実行完了を待ちます。
4. **Artifacts** から `AppAlarm-debug-apk` をダウンロード・解凍します。
5. 中に入っている `app-debug.apk` を Android 端末でインストールすると、既存アプリがそのまま最新版にアップデートされます。
