# アプリ！りまいんど！

Androidの指定時刻に、通知または全画面アラームを表示するアプリです。元の `appalarm_prefs` と `alarm_list_json` の保存形式を維持し、追加機能の値は既存アラームに既定値を適用します。

## ビルド

- Android Studio / GitHub Actions: JDK 17、Android SDK 34、Gradle Wrapper 8.5、Android Gradle Plugin 8.2.2
- GitHubへプロジェクトをpushし、Actionsの「Build Android APK」を実行します。`./gradlew assembleDebug` が動作し、成果物 `AppAlarm-debug-apk` にAPKを出力します。
- ローカルではプロジェクトルートから `./gradlew assembleDebug`（Windows: `gradlew.bat assembleDebug`）を実行します。

## アプリに含まれる主な機能

- アラームの作成・編集・削除、有効／無効の切替。既存アラームは一覧をタップして編集できます。
- 毎日、1回だけ、平日、日本の祝日を避ける設定。カレンダーから取り込む予定は指定日のリマインダーになります。
- 起動するアプリの選択。アプリ名の部分検索に対応し、日本語名を五十音順、英語名をA〜Z順で表示します。選択行は56dpアイコン・18sp文字です。
- 時計型の24時間時刻入力。
- 指定時刻に通常通知、または全画面アラームを表示。自動起動も選択できます。
- 通知モードの通知に「開く」「5分後に再通知」「今回は無視」を表示します。再通知回数の上限に達した場合や、設定で再通知を無効にした場合は、5分ボタンを表示しません。
- アラーム鳴動画面の停止チャレンジ、音量調整、フェードイン、スヌーズ。
- グループ／タグでの一覧絞り込み、次のアラームの表示、ホーム画面ウィジェット、クイック設定タイル。
- 停止・スヌーズ・無視の履歴、曜日／時間帯別の分析、テーマとMaterial You配色の設定。
- 再起動・時刻変更後のアラーム再登録。

## 権限と初回設定

1. 初回起動時に通知権限を許可します。
2. Android 12以降は「アラームとリマインダー」画面で正確なアラームを許可してください。拒否時も不正確なアラームで動作を試みますが、時刻どおりの通知は保証されません。
3. Android 14以降で全画面アラームを利用する場合、端末の「全画面通知」設定で本アプリを許可してください。端末メーカーの省電力設定によってバックグラウンド動作が制限されることがあります。
4. 再起動・時刻変更後はアラームを再登録します。

## 追加機能と状態

| 機能 | 状態 | 補足 |
|---|---|---|
| 計算問題チャレンジ | 実装済み | 停止ボタンで問題に回答 |
| QRコードチャレンジ | 外部設定が必要 | ZXing互換の「Barcode Scanner」アプリが必要。登録文字列があれば一致を確認 |
| アラーム別音量 | 実装済み | 0〜100%。Androidの音量・サイレント設定も影響します |
| 段階的再通知 | 実装済み | 再通知回数に応じ間隔を延ばし、最大60分 |
| カレンダー予定の取込 | 実装済み | アラーム編集で連携をONにし、カレンダー読取権限を許可。今後90日内の予定を1件ずつ一回限りのリマインダーに追加 |
| バックアップ／復元 | 簡易実装 | Androidファイル選択画面からGoogle Drive等を保存先に選択。アラーム編集の「クラウド保存対象」ONの項目だけをバックアップ対象にします。端末にDrive等のドキュメントプロバイダーが必要で、自動同期ではありません |
| スマートウォッチ通知 | 簡易実装 | Wear OS等の通知ミラーリングを利用。時計側の通知ブリッジ設定が必要 |
| 曜日・時間帯分析 | 簡易実装 | 保存済み履歴から曜日別スヌーズ率と時間帯別回数を表示。データ量が少ない場合は参考値です |
| Android 12+正確なアラーム権限 | 実装済み | 設定画面を開き、許可後に再登録。許可されない場合は不正確なアラームにフォールバック |
| Android 14+全画面アラーム | 外部設定が必要 | USE_FULL_SCREEN_INTENTを宣言。端末の許可設定と通知権限が必要 |
| アプリ選択の検索・並べ替え | 実装済み | アプリ名の一部で絞り込み。日本語名→英語名の順に表示 |
| アラーム編集・削除 | 実装済み | 一覧のアラームをタップすると編集画面を開きます |
| 通知モードの操作ボタン | 実装済み | 「開く」「5分後に再通知」「今回は無視」。再通知上限の設定を反映 |
| ロック中の即時アラーム | Android許可に依存 | 正確なアラーム権限と全画面通知を許可するとロック画面に表示。Android 14以降では全画面通知の許可も必要 |
| GitHub Actionsビルド | 未検証（この環境） | この作業環境のJavaは26のみでGradle 8.5が起動できません。CIはJDK 17に設定済みのためGitHub Actionsで確認してください |

## カレンダー・QR・時計連携

- カレンダーはAndroid Calendar Providerから今後90日間の予定を読み取ります。予定の追加や変更を監視する自動同期ではありません。
- QR読み取りはアプリにスキャナSDKを同梱せず、ZXing互換スキャナのインテント連携を使用します。対応アプリがなければストア等からBarcode Scannerをインストールしてください。
- 時計への通知はAndroidの通知ミラーリングを使用します。専用のWear OSアプリや時計からの操作機能は含みません。
- バックアップはユーザーが選んだドキュメント保存先へJSONを書き出します。クラウドアカウント、ネットワーク、サーバー鍵は不要ですが、Drive等の保存先アプリへのログインが必要です。

## 互換性と注意

- 既存のアラームJSONを読み込み、追加項目が存在しない場合は安全な既定値を使います。
- アプリID `com.achi.appalarm` はアップデート互換性のため維持しています。ランチャー表示名は「アプリ！りまいんど！」です。
- 通知チャンネルの音や重要度はAndroidのアプリ通知設定から調整できます。
- Android実機、端末メーカー別の省電力挙動、QRスキャナ連携、Wear OSミラーリングはこの作業環境では実機確認していません。
