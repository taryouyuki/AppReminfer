# アプリ！りまいんど！

既存の AppAlarm Android プロジェクトをベースにした改良版です。

## GitHub Actions で APK を作る

1. この ZIP を GitHub リポジトリに展開して push
2. GitHub の **Actions** を開く
3. **Build Android APK** ワークフローの完了を待つ
4. 実行結果の Artifacts から `AppAlarm-debug-apk` をダウンロード

ローカルでは JDK 17 と Android SDK が必要です。

```bash
./gradlew assembleDebug
```

## 今回の変更

- 表示名を「アプリ！りまいんど！」に変更（既存の applicationId は維持し、更新インストールと既存データの互換性を優先）
- ロボット＋スマートフォンの淡い配色のアプリアイコン
- アプリ名検索、名前順ソート
- 編集画面に曜日複数選択・日付指定・通知モード・音声読み上げテキストを追加
- 一度だけのアラームを発火後に自動無効化
- ウィジェットから次回1回だけをスキップ
- アラーム単位のスヌーズ設定を鳴動画面に反映
- Android 13以降の通知権限、Android 12以降の正確なアラーム権限への導線
- 通知チャンネル設定へのショートカット

## Android の許可について

Android 12 以降では「アラームとリマインダー」への許可が必要な端末があります。初回起動時にシステム画面を開き、設定画面からも再確認できます。Android 13 以降は通知の実行時許可も必要です。省電力機能が強い端末では、メーカー独自のバックグラウンド制限も解除してください。

## 実装上の注意・次の改善候補

- Android の通知音は通知チャンネル単位でOSが管理します。通知音を変更した後、Androidの設定画面から変更してください。
- 音声読み上げは端末にインストールされた日本語TTSエンジンに依存します。
- アプリが強制停止された状態では、Androidの仕様上アラーム受信が止まる場合があります。端末再起動後は BOOT_COMPLETED で再登録します。
- アラーム鳴動画面の確実な全画面表示には、端末・Androidバージョンによって全画面通知やバッテリー最適化の追加調整が必要です。
